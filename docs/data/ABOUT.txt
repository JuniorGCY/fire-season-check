Fire Season Check - data files
==============================

What these files are
- tocantins.json, grid.json, points/, geo.json: Tocantins, Brazil (main region).
- chaco/: the Argentine Chaco (second region), same file types, no border file.
- regions.json: which regions the page lists and where their files are (configuration, written by hand).
- Every other file here is generated by the offline pipeline in src/fogo (python -m fogo.cli build / geo).
  They are never edited by hand. Commands: see README.md.

Sources
- NASA FIRMS active fire data: MODIS Collection 6.1 (Terra and Aqua) and VIIRS S-NPP 375 m, archive and
  near-real-time (https://firms.modaps.eosdis.nasa.gov/). The newest ~150 days are near-real-time and provisional.
- geo.json (Tocantins border and town names): IBGE open data API (https://servicodados.ibge.gov.br/).
- No CONAE data is used.
